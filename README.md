# @mivama/ui

Shared React UI primitives for Mivama projects.

## Components

- `Button`
- `Card` and card subcomponents
- `Badge`
- `cn` utility

The package follows the same Base UI + shadcn-style component contract used by the Mivama Client Portal and Mivama Website.

```tsx
import { Button, Card } from "@mivama/ui";
import "@mivama/ui/styles.css";
```

Build with `npm run build`.
